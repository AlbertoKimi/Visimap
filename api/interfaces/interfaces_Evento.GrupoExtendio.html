    Interface GrupoExtendio

    Forma de un grupo en el FORMULARIO de creación/edición de eventos.

    Mantiene los campos en formato "amigable para UI" (nombre de provincia/país como string y un toggle modoOrigen). En el momento de guardar se traduce a id_provincia / id_pais para persistirlo según el modelo normalizado.
