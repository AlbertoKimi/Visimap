    Interface RegistroEvento

    Vista detallada de un registro de asistencia a evento, incluyendo datos anidados del evento y el usuario que lo gestiona.

    Tras la normalización de grupo_visitante, las columnas tipo_origen/origen desaparecen. Se exponen helpers calculados (origen y tipo_origen) en el mapeo de datos para mantener compatibilidad de UI sin tocar la BD.
